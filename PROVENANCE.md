## Academy maintenance

- Support floor: macOS High Sierra 10.13.
- Method: full audit before publication; findings and remediation documented in the Academy's program records; builds verified on real High Sierra hardware before any release claim.
- Identity: Academy builds of this code ship under Academy bundle identifiers (`com.detroitautomationacademy.*`) per the program's Identity + Provenance Standard — upstream identifiers remain in upstream's own builds only.

Upstream is archived and unmaintained; this fork exists so the software keeps working on the systems it was written for. All credit for the original work belongs to its authors.
